(`docs/DESIGN-*.md §n`); **замерить до того, как трогать** (пункт называет свой измеритель);
собрать; посмотреть глазами на `dev.html` в окне 390×844; закоммитить локально; вычеркнуть пункт и
тем же коммитом унести его тело в архив. Политика 11.09 в силе: правим без тестов, коммиты
локальные, весь прогон (-Full, -Mobile, -Mutants) — только перед пушем. Этапы 0–1 разрешены

написаны после этой критики. Правила автора с плейтеста связывают каждый пункт: экран никогда не
теряет прокрутку; каждый экран отвечает «чтобы что?» до переделки; оптимизировать без потери

## Второй проход по всему плану (14.09) — швы, постоянный чеклист, новые механики

**Швы между системами** (каждый — строкой в своём пункте; здесь, чтобы не потерялись):
- **Модули → чертёж (M478).** Сегодня `capOf` делят модули и детали; когда уровни станут

  числом не показываются.
- **Дроны и дальние товары (M465).** Дроны не копают пояса 2–3, товары пояса 1 продают по цене пояса

  заходе в кольцо, не при выбросе из него.
- **Первый час (M452, M472).** В домашней системе жест — ГЛАВТРАССЫ, и это первая строка первого часа;
  замполит вручает новичку жетон («первый — за счёт трассы») — метро встречают в первый час, а не

- **Область схемы (M470).** Бумага показывает твою линию, кольца, которые она встречает, и соседей;
  щипок/прокрутка за большим — никогда всю бесконечную сеть. «Край» — у каждого свой (без общего
  состояния).
- **Место M484 на паде.** Две постоянные кнопки остаются; особая система — **долгое нажатие** пада
  ДЕЙСТВИЕ с перезарядкой, нарисованной ободом пада — третьей кнопки над миром нет.

  перебазирован.
- **Ворота этапа 0 перегоняются после каждого этапа** — каждый этап добавляет растр (выпечка
  галактики, дорожка, неон, поездка); этап, ломающий ворота, не закрыт.

**Постоянный чеклист закрытия любого пункта этапов 2–7:** новые поля `G` в `snapshot()` или

посылки · эталоны пересняты для затронутых сцен (`-Accept`, `-Mobile`, 1440) · новая визуальная
система получает выпуск альманаха (неон, синька, кольцо) · строки оракулов зелёные · ворота этапа 0 ·
один гэг и одна доброта названы в патчноуте (закон юмора) · старый сейв грузится.

**Точки выкладки (пуш после полного прогона):** после этапа 0 («кадр»), после 0b, после этапа 2
(«чья земля»), после этапа 3 («дорога»), дальше по этапу.
