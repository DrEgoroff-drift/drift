# Collected-wave review, 13 November 2026

Scope: every changed file in `0aa51308..b14c340b` (25 collected commits,
68 paths), plus the release repairs in `f2987a7f` and this follow-up.
Each source diff was read with its relevant producers, consumers and save paths.
Generated files were checked through their inputs and rebuilds, not by reading
the concatenated game or symbol index as independent source.

This is a review of all changes in those 68 files, not a claim that every
unchanged line in the whole game has been proved correct. Author art/plan work
and the 23 excluded balance proposals were not imported.

## Findings repaired

- `routeNext` compared a station key with a leg object and always fell back to
  the first station. It now resolves the cursor's station key and finds the
  incoming/outgoing legs by endpoint.
- Bulk base life accumulated production before consumption, losing stock at
  capacity, using the wrong food multiplier, and ignoring per-shift rounding,
  freezing and conservation. The bounded catch-up now uses the same resource
  step as ordinary operation; income/mining follows life support for each shift.
  Historical guest/crew/theft events remain excluded from the old bulk interval.
- Barge extra legs were capped per catch-up batch, so visiting more often changed
  progress. The cap is now one extra leg per shift.
- Repeated locker handovers could reuse a pawn ID and remove two parts with one
  purchase. New IDs avoid existing and previously purchased pawn lots.
- A planet's wall condition could be satisfied by another planet's wall. Only
  station-pinned stories may search the whole system.
- Krapiva's older departure could run after the relay continuation. Restored
  the continuation guard; suppressed Guram's old balance line after its reversal.
  Migrated the old planet pin of `pad_taken` when loading a save.
- Corrected remaining promises: loom affects drones, the live sample is credited
  immediately, unique-ship parts arrive in inventory, and a rescue does not
  guarantee a crew seat when the crew is full.
- Lost pointer capture now clears both the raw pointer and helm gesture state.

The earlier release repair also fixed free reverse stick thrust, freight lost
between saves, a nonexistent mushroom sale promise, and analytics crashing the
Node harness after its green result.
